# 12 — Internationalization & Bilingual Architecture

> This document details the runtime bilingual architecture (French / English) of **LPI Certification Prep**, located in `src/i18n/`.

---

## 1. Bilingual Architecture Principles

Because Linux certifications are international, candidates frequently switch between French (for conceptual learning and explanations) and English (the official exam language used at Pearson VUE test centers).

### Key Architectural Pillars:
1. **Instant Runtime Switching**: Language switches dynamically in React state without page reloads or loss of in-progress exam timers.
2. **Type-Safe Dictionaries**: Translation keys are strictly typed via TypeScript interfaces, preventing missing keys at compile time.
3. **Automatic Locale Detection**: Detects user browser preferences (`navigator.language`) upon initial visit, with persistent manual preference storage in `localStorage` (`lpi_preferred_language`).
4. **Bilingual Documentation Modules**: Technical documentation and guides are provided in both French and English, synchronizing with the user's active language preference.

---

## 2. Implementation Pattern

```typescript
// src/i18n/LanguageContext.tsx
export type Language = 'fr' | 'en';

export interface LanguageContextType {
  language: Language;
  setLanguage: (lang: Language) => void;
  isFrench: boolean;
  t: TranslationDictionary;
}
```

Components access translations cleanly through the `useLanguage()` hook, maintaining spotless separation between presentation markup and localized string constants.
